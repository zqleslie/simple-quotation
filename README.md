# 简易报价单生成器

> 填写信息，一键生成专业报价单，支持浏览器打印/导出 PDF

[在线演示](https://zqleslie.github.io/simple-quotation/)

## 使用方法

1. 填写您的公司名称、联系方式
2. 填写客户名称
3. 添加项目明细（名称、单位、数量、单价）
4. 填写备注信息（可选）
5. 点击「生成预览」查看报价单
6. 点击「打印/PDF」导出为 PDF 文件

## 特色功能

- 📝 动态添加/删除项目行
- 💰 自动计算小计、税费、总计
- 🖨️ 浏览器打印/导出 PDF
- 📱 手机端完美适配
- 🔒 纯前端运行，数据不上传

## 技术栈

- 纯 HTML + Tailwind CSS + Vanilla JS
- 零依赖，零构建
